# ชุดตรวจรับคุณภาพคำอ่านภาษาไทย V1.5 (ร่าง)

V1.4 ยังอยู่บน Production ตามเดิม ชุดนี้มีไว้ให้ Owner อ่านและตัดสินเท่านั้น
ห้าม Merge หรือ Deploy ก่อนมีคำยอมรับอย่างชัดเจน

โปรดอ่าน `known-time-report.pdf` และ `unknown-time-report.pdf` แล้วพิจารณา:

1. หน้าแรกเปิดด้วยความขัดแย้งเฉพาะดวงและชวนอ่านต่อหรือไม่
2. อดีต ปัจจุบัน 12 เดือน และช่วงชีวิตถัดไปพาเรื่องเดินหน้า ไม่เล่าเรื่องเดิมหรือไม่
3. งาน เงิน ความสัมพันธ์ และสุขภาวะมีน้ำเสียงและข้อสรุปต่างกันจริงหรือไม่
4. คำแนะนำถูกจัดลำดับ ไม่ติดท้ายทุกย่อหน้าหรือไม่
5. บทสรุปก่อนภาควิธีอ่านให้ความรู้สึกจบ และข้อจำกัดยังหาอ่านได้ง่ายหรือไม่

Known fixture คือ 1982-06-06 เวลา 00:03 เชียงใหม่ ลัคนากุมภ์ 9°24′ ส่วน
Unknown-time ไม่ระบุเวลา ลัคนา หรือเรือน ภาพ render ทุกหน้าอยู่ใน `renders/`.
