# R2 root cause and correction

R1 introduced `_assignPrimaryForecastHomes`, which filtered 12 supported domain/horizon blocks down to four total. That single ownership mistake caused all eight reported symptoms: missing four-domain coverage, UI mismatch, absent-list/RangeError and null failures, weakened known/unknown sensitivity, synthetic projection crashes, headline/body disagreement, and reduced depth. The readability failure was exposed in the same rejected test run and corrected without deleting domain content.

R2 removes the filter and restores four supported domains in each of current, next 12 months, and next life phase. The Claim Ledger now describes each domain/horizon primary claim rather than deleting repeated domain identities. Risks, triggers, consequences and actions remain horizon-specific. Tests restore the established 12-block assertions.

The four biography-like timeline statements were reclassified as cautious synthesis and rewritten as patterns to compare with lived experience. No event is stated as having happened without direct evidence. The opening grammar was corrected and shortened; the closing now provides a responsible synthesis with no more than three priorities before methodology.
