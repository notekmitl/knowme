# Root cause

R6 ผูกการสร้างข้อความกับเป้าหมาย exact-reuse โดยเติม motif, phase และกรอบ ownership ลงในแทบทุก claim ตัวเลขจึงดูดีขึ้น แต่แนวคิดนามธรรมกลายเป็นผู้กระทำและข้อความราย domain เสียความเป็นภาษาไทยธรรมชาติ

R7 ถอนการเติมดังกล่าวที่ composition layer ใช้ข้อมูล motif/phase เพื่อวางแผนภายในเท่านั้น และให้ประธานของข้อความเป็นคน การตัดสินใจ เหตุการณ์ หรือหลักฐานของ domain นั้น
