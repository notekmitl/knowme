# Noto Sans SC

Bundled file: `NotoSansSC-Regular.ttf` (the official variable-weight file is
stored under this stable application asset name).

Source: Google Fonts, `ofl/notosanssc/NotoSansSC[wght].ttf`:
<https://github.com/google/fonts/tree/main/ofl/notosanssc>

The font is distributed under the SIL Open Font License 1.1. The license text
is already bundled at `../noto_sans_thai/OFL.txt`. This CJK fallback is used by
the BaZi PDF exporter so Chinese pillar characters are embedded and do not
depend on a device font or a runtime download.
