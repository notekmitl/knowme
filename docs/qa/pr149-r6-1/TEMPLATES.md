# ตรวจข้อความระดับต้นทางและผลประกอบ r6.1

ผู้ตรวจพบข้อความตกหล่นจาก r6 เจ้าของยังไม่ได้ตัดสินภาษา r6

ผลด้านล่างบันทึกสถานะของ r6.1 รายการค้างทั้งสี่กลุ่มปิดใน r6.2 พร้อมคำอ่านที่ประกอบจริงและเหตุผลรายแขนง [ผลตรวจ r6.2](../pr149-r6-2/TEMPLATES.md)

เทียบข้อความต้นทางกับผลที่ผ่าน base map, r6 map และ r6.1 จากตัวอ่านจริง ชุดประกอบมีไทย 24 เคส จีน 242 ชุดเคสและปี และตะวันตก 72 ชุด ใช้ A/B, owner-wording และไม่ทราบเวลาเกิดแยกสำหรับดวงรวม ฟอร์ม และเว็บจริง ชุดตะวันตกพบวลีต้นทางครบทั้ง 253 รายการจากพจนานุกรม 14 กลุ่ม ตารางนับข้อความที่ยังปรากฏคำเดิมใช้หาวลีที่จะอ่านซ้ำ คำเดิมที่ปรากฏอาจเป็นภาษาที่ชัดอยู่แล้วหรือชื่อข้อมูลดวง [รายการวลีและจำนวนที่พบ](template-counts.json) · [คำอ่านที่ประกอบจริง](FULL_READINGS.md)

## รันตรวจออฟไลน์

```powershell

flutter test --dart-define=COPY_SNAPSHOT=.preview-qa/r6-1-assembled.json --dart-define=COPY_OWNER_SNAPSHOT=.preview-qa/r6-1-owner.json docs/qa/pr149-r6-1/capture_test.dart test/trial_readability_snapshot_test.dart test/three_tradition_life_reading_test.dart
```
