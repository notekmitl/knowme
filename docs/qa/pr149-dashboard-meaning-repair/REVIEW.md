# PR149: ซ่อมหมวดและตรวจความหมาย r3

ฐาน: `6261951` / application `ffc960b` / `trial_plain_th_20261110_r2`. ใช้ input และ as-of `2026-11-10T03:00:00Z` เดิมใน snapshot test. รายละเอียดทุกย่อหน้าอยู่ใน `assembled-reading-review.json`; คอลัมน์ก่อนคือข้อความ r2 ที่ประกอบจริงในหลักฐานเดิม ไม่ใช่ expected ที่สร้างจากโค้ดใหม่. ต้นฉบับก่อนปรับภาษายังคงอยู่ในช่อง `before` ของ JSON ทั้งสองรุ่น.

## ต้นเหตุที่พิสูจน์ได้

UI อ่าน `analysis.consumerViewState.lifeDashboard` ตามลำดับหัวข้อจาก presenter อย่างถูกต้อง. `lifeAspectDashboardParts` เลือกธีมและ variant ตาม seed. ตัวเลือกสำรองใน `ThaiMirrorThemeVariants.aspectHintVariants` กลับอ่าน work→life.money, money→life.work, love→life.health, health→life.love และ luck→life.work. Fixture B เลือกตัวเลือกนี้ทั้งห้าการ์ด จึงผิดก่อนถึง UI; ไม่ใช่การเรียงการ์ดหรือการแปลภาษา r2 และไม่ใช่ cache.

เพิ่ม metadata ของหมวด/ธีม/ต้นทางติดกับตัวเลือกเดิม รักษาทั้ง pool ลำดับ deduplication seed และ used-theme/current-state/action เดิม. Trial projection ซ่อมการอ้างอิงไปยัง field ของหมวดที่ร้องขอในธีมเดิม เฉพาะเมื่อ metadata ยืนยันว่ามาจากคนละหมวด. ไม่เดาหมวดจากถ้อยคำ ไม่เปลี่ยน registry หรือสูตรเลือกหลักฐาน. Raw view/report/ผู้ใช้เว็บหลักยังใช้ค่าเดิมตามขอบเขต; รายละเอียดไทยใช้ narrative composer คนละเส้นทางและเอกสารพิมพ์ร่วม ซึ่งตรวจแยกแล้ว.
