# ตรวจข้อความตอนยุบและขยาย r6.3

เจ้าของอ่าน r6.2 แล้วแจ้งว่ายังอ่านไม่เข้าใจ โดยเฉพาะข้อความแรกของการ์ดตอนยุบ ผลตรวจภาษารอบก่อนจึงยังไม่ใช่การยอมรับจากเจ้าของ

`ThreeTraditionReportPage._OverallTopicDetails` ใช้ย่อหน้าแรกจาก `TrialOverallTopicCopy` ตอนยุบ ตอนขยายแสดงย่อหน้าแรกและรายละเอียดต่อกัน ผลในตารางมาจากคำอ่านที่ประกอบจริง โดยคงวิธีแสดงการ์ดเดิม [คำอ่านจริง](ASSEMBLED.md) · [ก่อน–หลัง](READINGS.md)

| หัวข้อ | ตอนยุบ | ตอนขยายและต้นทาง |
| --- | --- | --- |
| การงาน | งานแบบที่มีแนวโน้มเหมาะกับคุณ จากกลุ่มที่ BaZi เลือก | แยกวิธีทำงานตามเจ้าเรือนไทยจากทักษะดาวพุธตะวันตก ข้อตกลงก่อนรับงานและความเสี่ยงเมื่อคุยกันไม่ชัดอยู่กับเงื่อนไขเดิม |
| การเงิน | สิ่งที่มีแนวโน้มสำคัญต่อเงิน จากกลุ่มที่ BaZi เลือก | ระบุให้ชัดว่าสิ่งที่เทียบคือทางเลือกในการจัดการเงิน คำแนะนำเงินร่วมและวงเงินลงทุนอยู่กับแขนง BaZi เดิม |
| ความสัมพันธ์ | วิธีแสดงความรักหรือสิ่งที่ต้องการจากการคบกัน ตามดาวศุกร์ตะวันตกที่เลือก | ข้อสังเกตของไทยขึ้นต้นด้วยเรื่องที่เกี่ยวข้อง แขนงจันทร์เก็บ “คนรอบข้าง” และบอกว่าต้นทางไม่ได้ระบุว่าเป็นใคร คำอ่านเรื่องความผูกพันยังใช้แขนง true/false/null เดิม |
| ดูแลตัวเอง | สิ่งที่ช่วยให้รู้สึกพร้อมรับมืออีกครั้ง จากคำอ่านดวงจันทร์ตะวันตกที่เลือก | คงวิธีที่เหลือและคำแนะนำ BaZi จากเดิม แยกข้อสังเกตจากเรือนที่ 6 ไว้อีกย่อหน้า และบอกว่าต้นทางไทยไม่ระบุว่าจะมีแรงขึ้นหรือเหนื่อยกว่าเดิม |

ตรวจเจ้าเรือนอาทิตย์ จันทร์ อังคาร พุธ พฤหัสบดี ศุกร์ และเสาร์ในทุกหัวข้อที่เคยใช้ `_houseAction` ตรวจข้อความสำรองโดยใช้ค่าต้นทางที่ไม่มีในตารางแปลง เจ้าเรือนพุธของการ์ดดูแลตัวเองและเจ้าเรือนจันทร์ของความสัมพันธ์ตรวจร่วมกันด้วย fixture สังเคราะห์ที่ตั้งค่าเพื่อให้ผ่านแขนงข้อความเท่านั้น [ผลประกอบรายเจ้าเรือน](ASSEMBLED.md#เจ้าเรือนทั้งเจ็ดและคำอ่านที่ใช้ร่วมกัน)

ค้นวลีเดิมทั้งสี่มุมมอง พบคำขึ้นต้น “การดูแลกำลังของคุณเริ่มจาก…” ในข้อความสำรองของดวงรวม จึงใช้ข้อจำกัดเดียวกับรายงานไทย ตัวอย่างไทย A/B มีการแก้เฉพาะย่อหน้าแรกของหัวข้อสุขภาพและพลังชีวิต ข้อสังเกตเวลาพักและข้อจำกัดทางการแพทย์ยังอยู่ คำอ่านจีนและตะวันตกของเคสเทียบใช้ถ้อยคำเดิม [ผลเทียบ](evidence-parity.json)
