## ผลตรวจโปรแกรมและปลายทาง

- Application `01567be` ผ่าน required CI ก่อนเผยแพร่เวลา 18:42:53 น. กรุงเทพฯ เฉพาะ Hosting site `knowme-trial-694e1` ที่ version `5d7769e42db14297` [CI application](https://github.com/notekmitl/knowme/actions/runs/43209695813) · [สิทธิ์ Hosting](hosting-permissions.json)
- ชุดตรวจที่เกี่ยวข้องผ่าน 76 รายการ รวมการรักษาคำเชื่อมและเงื่อนไขเมื่อแบ่งย่อหน้า ตรวจชุดประกอบไทย 24 เคส จีน 49 ชุดเคสและปี ตะวันตก 72 ชุดราศี เรือน และมุมดาว รวม A/B, owner-wording และข้อมูลไม่ครบ ผลดวงที่เลือก หลักฐาน หมวด และข้อความ raw ตรงกับ r5.2 [ชุดตรวจ](fixture-inventory.json) · [ผลเทียบข้อมูล](evidence-parity.json)
- ตรวจ Chromium ปลายทางทั้งสามขนาด 390×844, 1280×800 และ 1920×911 ครบทั้งสี่แท็บ เปิด–ยุบตรงหัวข้อ คำอ่านที่แสดงบนหน้าจออยู่ในคอลัมน์เดิม ตรวจแถวช่วงเวลาจีนจากภาพที่เลื่อนผ่านแต่ละช่วง เพราะ Chromium แสดงข้อความที่เลือกคัดลอกได้เหล่านี้บนหน้าจอโดยไม่มีเนื้อหาแถวใน accessibility snapshot [ผลตรวจ](release-summary.json)
- ตรวจ browser print ของไทยจากปลายทางทั้งข้อความและภาพทุกหน้า แต่ละชุดมี 4 หน้าและพบครบ 60 ย่อหน้าใน PDF ทั้งสามชุด เอกสารเดียวกันใช้แสดงผลบนเว็บ [ผลตรวจ](release-summary.json)
- ทราบเวลาใช้ 2 POST ต่อรอบ ไม่ทราบเวลาใช้ 0 การเปิด–ยุบและสลับแท็บไม่เพิ่มคำขอ ทั้งหกรอบไม่พบ Auth, Firestore, Production API หรือการเขียนข้อมูลอื่น [ผลตรวจ](release-summary.json)
- Browser โหลด pin `trial_plain_th_20261112_r6` และ hash ตรงกับ build ที่เผยแพร่ เว็บหลัก version `d32e72678324e634` และเครื่องคำนวณ trial revision `knowme-overall-pr149-preview-00004-kt9` ตรงกับก่อนเผยแพร่ [hash ปลายทาง](hosted-hashes.json)

## ข้อสังเกตเรื่องช่องทาง

- ภาพสรุป 12 เดือนแสดงในรายงานไทยบนเว็บทั้งสามขนาด ตรวจข้อความบนภาพและยืนยันว่าข้อมูลรายเดือนยังไม่พร้อมตามกฎเดิม ในรอบทดสอบ Browser print ของ trial ได้ฉบับข้อความสี่หน้าเหมือนช่องทางเดิม ภาพสรุปแยกไม่ได้อยู่ใน PDF ที่สร้างจากเส้นทางนี้ [ภาพสรุปบนมือถือ](annual-hosted-a-390-chrome.png) · [ภาพทุกหน้าของ PDF](hosted-a-390-chrome-pages.png)
- ตรวจผลประกอบจริงหลายเงื่อนไขตาม [รายการ fixture](fixture-inventory.json) คำอ่านบนเว็บใช้ผล V3 ตามเงื่อนไขเดิม ข้อความสำรอง V1/V2 และข้อมูลไม่ครบตรวจจากรายงาน offline ส่วนคำตอบไม่ทราบเวลาเกิดตรวจจากฟอร์มปลายทางจริงทั้งสามขนาด
