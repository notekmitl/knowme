# PR #149 · r5 อ่านดวงรวมโดยไม่ต้องเดา

เจ้าของอ่าน r4 แล้วแจ้งว่าคำอ่านยังเข้าใจยาก ส่วนการแบ่งย่อหน้าและการจัดหน้าทำได้ดี รอบ r5 แก้ภาษาของการ์ดดวงรวมทั้งสี่ โดยใช้ภาพ สี คอลัมน์ และการเปิด–ยุบแบบเดิม **r5 ยังรอเจ้าของทดลองอ่าน** การตรวจเทคนิคกับการตรวจความหมายโดยผู้ช่วยเป็นคนละส่วนกับผลอ่านของคนจริง [เว็บทดลอง](https://knowme-trial-694e1.web.app/beta/thai) · [PR #149](https://github.com/notekmitl/knowme/pull/149)

## คำอ่านและต้นทาง

- [อ่านทั้งหัวข้อก่อน–หลังของ A/B และ owner-wording](READINGS.md) พร้อมคำอธิบายทีละย่อหน้า ตัวอย่าง owner-wording ใช้หลักฐานที่เลือกจาก fixture สังเคราะห์ซึ่งประกอบข้อความต้นทางได้ตรงกับคำอ่านที่บันทึกไว้
- [คำอ่านจริงของแขนงที่ได้รับผล](branch-readings.json) ครอบคลุม 12 ราศีของพุธ ศุกร์ และจันทร์ ดาวเจ้าเรือนไทย 7 แบบ กลุ่มงานจีน 5 แบบรวมกลุ่มที่ได้พร้อมกัน และระดับสมดุล 3 แบบ
- [เทียบข้อมูลก่อน–หลังที่วันอ้างอิงเดียวกัน](evidence-parity.json) ข้อมูลดวงที่เลือก หลักฐาน หมวด คำอ่านเดิม ข้อความรายศาสตร์ และผลเรื่องข้อมูลไม่ครบกับข้อขัดแย้งตรงกับ r4
- ใช้ประโยคสั้นและบอกก่อนว่าพูดถึงอะไร ข้อสังเกตจากไทยและตะวันตกอยู่คนละย่อหน้า คำว่า “เมื่อ” ใช้เฉพาะกับเงื่อนไขที่มีความหมายเดิม เช่น การคุยกันให้ชัดในเรื่องความสัมพันธ์

## ตรวจโปรแกรม

- Flutter regression ในเครื่องผ่าน 65 รายการ รวมการแยกวิธีทำงานออกจากทักษะเรียนรู้ การรักษาคำว่า “อาจ” และเงื่อนไขของคำเตือนเรื่องงานและเงิน การจับคู่การ์ด r3 และการเปิด–ยุบสามขนาด
- ก่อนเผยแพร่ ใช้ Chromium ทดสอบ bundle r5 กับ fixtures เดิมที่ 390×844, 1280×800 และ 1920×911 ข้อความแสดงครบในคอลัมน์เดิม ยุบแล้วเหลือย่อหน้าแรก ขยายแล้วอ่านได้ทุกย่อหน้า เคสไม่ทราบเวลา 390×844 แสดงข้อความเดิมและใช้ 0 POST
- เว็บและเอกสารพิมพ์ใช้ข้อความรายศาสตร์เดิม ตรวจข้อความเอกสารพิมพ์ไทย 46 ย่อหน้าจาก DOM เท่ากับหลักฐานเดิม ทั้ง A และ B
