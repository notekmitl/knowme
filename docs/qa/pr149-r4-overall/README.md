# r4 คำอ่านดวงรวมบนเว็บทดลอง

เจ้าของอ่าน r3 แล้วแจ้งว่า “อ่านไม่รู้เรื่อง ต้องให้เข้าใจง่ายกว่านี้ และแบ่งย่อหน้าด้วยก็ดี” สถานะ r3 คือเจ้าของยังไม่รับภาษา ส่วน r4 ผ่านการตรวจเทคนิคและ **รอเจ้าของทดลองอ่านอีกครั้ง**

r4 ใช้ข้อความจากตัวเลือกเดิมในแต่ละศาสตร์เพื่อเขียนประโยคใหม่และจัดย่อหน้าตามเรื่อง เมื่อยุบการ์ดจะเห็นย่อหน้าแรกเต็ม เมื่อเปิดจะเห็นย่อหน้าที่เหลือในลำดับเดิม ปุ่มยุบขยายอยู่ตำแหน่งเดิมและระบุชื่อหัวข้อ บนคอมพิวเตอร์การ์ดเรียงในคอลัมน์เดียวเต็มพื้นที่ด้านขวาของภาพ ชื่อ “ดูแลตัวเองในแต่ละวัน” ใช้กับหัวข้อที่รวมการดูแลตัวเอง วิธีตั้งหลัก และคำระวัง [คำอ่านครบก่อนและหลัง](READINGS.md)

## ผลตรวจ

- Focused Flutter regressions ผ่าน 65 tests รวม fixture A/B การเปิดปิดทุกหัวข้อที่สามขนาดจอ ระยะย่อหน้า ข้อมูลไม่ครบ การเลือกหลักฐาน และการผูกหมวด r3 ข้อความดั้งเดิม หลักฐาน ข้อขัดแย้ง และผลประกอบของแท็บไทย จีน และตะวันตกเท่ากับ snapshot ก่อนแก้
- Fixture คำอ่านเจ้าของเทียบข้อความต้นทางทั้งสี่หัวข้อกับผลทดสอบเดิมที่บันทึกไว้ตรงทุกตัวอักษร รวมตัวเลือกงานค้นคว้าและแผนการเงินระยะยาว ใช้ค่าตัวเลือกเนื้อหาสังเคราะห์สำหรับทำซ้ำข้อความ จึงไม่มีการเก็บหรืออนุมานข้อมูลเกิดจากภาพ
- Chromium ปลายทางที่ 390×844, 1280×800 และ 1920×911 ตรวจครบสี่หัวข้อในสถานะยุบ ขยาย และยุบอีกครั้ง ข้อความใน DOM ตรงทั้งย่อหน้า อยู่หัวข้อที่ระบุ และปรากฏครั้งเดียว ระหว่างย่อหน้าห่าง 14 px พื้นที่ข้อความ 316 px บนมือถือและ 452 px ในคอลัมน์ด้านขวาบนคอมพิวเตอร์ กรณีย่อหน้าที่ยาวเกินช่วงจอเลื่อนอ่านถึงท้ายย่อหน้าได้
- การเปิดรายละเอียดและสลับแท็บทั้งสามใช้ข้อมูลจากการคำนวณเดิม การทดสอบจริงทราบเวลาใช้ 2 POST (HTTP 200) ต่อรอบ และไม่ทราบเวลาใช้ 0 ที่ทุกขนาดจอ บันทึกเครือข่ายไม่พบ Auth, Firestore, Production API, การเขียนอื่น หรือข้อผิดพลาดในแอป
- เส้นทางเอกสารพิมพ์ไทยจากแท็บเดิมตรงกับ r3 ทั้ง 46 ย่อหน้าในแต่ละรอบทราบเวลา งาน r4 อยู่ที่การแสดงผลดวงรวมซึ่งไม่มีทางออก PDF จึงตรวจความเท่ากันของ print DOM ที่ใช้ร่วมกับ PDF ไทย [ผลตรวจปลายทาง](release-summary.json)
