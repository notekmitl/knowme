## Exact blockers

1. Canon/engine sources describe planet, period, role, relationship and domain signals but do not define event-family causation or movement
2. A qualified Thai-astrology domain authority must define or approve how independent signals map to each event family, including negative cases and safe vocabulary
3. Values 64, 68, 46 and fixed 75/80 have no accepted source; population percentiles measure frequency only
4. A historical outcome dataset with labeled horizons/events is required to estimate predictive validity, false positives, false negatives and any real confidence value
5. Relationship status can prevent an impossible branch but cannot turn a love tendency into entry/ending evidence
6. V1 produced two profiles with opposing event candidates before its unsourced confidence resolver; an approved semantic conflict rule is still missing
7. No KnownTimeRequired=false event rule exists; Unknown must remain a short reduced report
