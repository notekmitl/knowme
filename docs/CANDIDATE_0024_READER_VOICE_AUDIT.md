## Why the Production copy became too short

The active Candidate 0023 runtime uses one fixed paragraph per prediction owner. Its OR9 evidence gate checked 23 exact spans and required every remaining span to be exact-copy supported. The accompanying semantic ownership audit also treated all cross-section meaning overlap as something to drive toward zero. That combination correctly removed unsupported Candidate 0022 claims, but it also encouraged a one-line-per-section result and prevented a useful overview from previewing later detail.

Candidate 0023 therefore kept only eleven compact prediction owners: overview, three past periods, current, four current domains, support and rolling 12 months. The runtime has typed current material for career, finance, relationship and health, plus next-12-month career and finance material, while the source dossier also contains direct facts for the childhood constraint, the 11–62 rising direction, current flow, work, finance and support. Some of that authority was present in metadata but not explained in reader-friendly prose.

Reader Voice V3 changes the editorial contract, not the evidence. It allows the same authorized fact to be stated and then explained in a distinct sentence, and it introduces `INTENTIONAL_SUMMARY_TO_DETAIL` so a high-level overview can lead into lower-level sections. It still blocks any new event, timing, causal link, certainty change or advice presented as prediction.
